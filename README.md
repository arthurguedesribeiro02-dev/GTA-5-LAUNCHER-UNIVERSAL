# GTA-5-LAUNCHER-UNIVERSAL
Launcher para GTA 5 Lite no Android, desenvolvido para facilitar a instalação e execução do jogo em ambientes compatíveis. Inclui suporte a versões Lite, integração com emuladores como Winlator Ludashi e organização dos arquivos necessários. Projeto voltado a testes, compatibilidade e praticidade para jogar GTA 5 em dispositivos Android.
